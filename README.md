## 🧠 Engineering Principles I Ship By

```
📐  Event sourcing + Saga patterns for distributed consistency
🔒  Idempotency keys on every financial mutation
📊  Double-entry ledger as the ground truth for money movement
🏗️  Finite State Machines for lifecycle-driven domain models
🐇  RabbitMQ message contracts — typed, versioned, and never assumed
🔁  Graceful reconnect, DLX routing, and circuit breakers by default
🛡️  UFW + Docker hardening + SSH key-only access in production
```
